🔷 PRZYROSTKI
I. PRZYROSTKI TWORZĄCE PRZYMIOTNIKI
-j-
Funkcja: tworzenie stopnia wyższego przymiotników.
Znaczenie: „bardziej X / w większym stopniu przejawiający cechę X”.
Typ: deadiektywny, pierwotnie deradykalny.
Geneza:
 Praindoeuropejski formant stopnia wyższego *-yes- / *-is-, rozwinięty w prasłowiańskim w formacje porównawcze z *-j-.
Przykłady:
* nowy → nowszy
* stary → starszy
* młody → młodszy
* wysoki → wyższy
________________


-n-
Funkcja: nomen adiectivum — tworzenie przymiotników relacyjnych, jakościowych i rezultatywnych.
Znaczenie: „związany z X / posiadający X / charakteryzujący się X”.
Typ: denominalny, dewerbalny, deradykalny.
Geneza:
 Kontynuuje PIE *-no-, jeden z podstawowych indoeuropejskich formantów przymiotnikowych. W prasłowiańskim występował jako *-nъ / *-no.
Przykłady:
* wodny
* nocny
* kamienny
* jedwabny
________________


-in-
Funkcja: nomen adiectivum — tworzenie przymiotników posesywnych i relacyjnych.
Znaczenie: „należący do X / właściwy X / pochodzący od X”.
Typ: denominalny.
Geneza:
 Prasłowiański formant posesywny *-inъ. Jego dalsza geneza nie jest pewna; odpowiedniki z elementem *-in- występują również poza słowiańszczyzną.
Przykłady:
* babin
* materinъ
* zvěrinъ
________________


-t-
Funkcja: nomen adiectivum — tworzenie przymiotników rezultatywnych i stanowych.
Znaczenie: „będący wynikiem X / poddany X / znajdujący się w stanie wywołanym przez X”.
Typ: deradykalny, dewerbalny.
Geneza:
 Kontynuuje PIE *-to-, stary indoeuropejski formant przymiotników rezultatywnych.
Przykłady:
* bity
* szyty
* kuty
* dany
________________


-r-
Funkcja: nomen adiectivum — tworzenie archaicznych przymiotników jakościowych.
Znaczenie: „mający cechę X / charakteryzujący się X”.
Typ: deradykalny.
Geneza:
 Kontynuuje PIE *-ro-, stary formant przymiotnikowy należący do indoeuropejskiego systemu formacji jakościowych.
Przykłady:
* *rьdrъ „czerwony”
* *syrъ „surowy”
* stare formacje typu *-ro-
________________


II. PRZYROSTKI TWORZĄCE RZECZOWNIKI
A. Jednostka / sprawca / nosiciel cechy / rezultat
-k-
Funkcja: nomen rei / nomen agentis / indywidualizacja / zdrobnienie / nosiciel cechy.
Znaczenie: „jednostka związana z X / rezultat X / nosiciel X / mały X”.
Typ: deradykalny, denominalny, deadiektywny, dewerbalny.
Geneza:
 Kontynuuje PIE *-ko-. W prasłowiańskim element *-k- stał się podstawą bardzo rozbudowanej rodziny derywacyjnej.
Przykłady:
* *znakъ → znak
* *zvąkъ → dźwięk
* *zorkъ → zrak
* *tukъ → tuk
________________


-i-
Funkcja: femininum / motionis.
Znaczenie: „żeńska odpowiedniczka X”.
Typ: denominalny.
Geneza:
 Kontynuuje PIE *-ih₂, jeden z podstawowych formantów tworzących żeńskie odpowiedniki nazw istot żywych.
Przykład:
* pani
________________


-ę-
Funkcja: nomen iuvenile.
Znaczenie: „młody osobnik X”.
Typ: denominalny.
Geneza:
 Prasłowiańskie *-ę kontynuuje starszą formację na *-ent-. Temat *-ęt- zachował się w przypadkach zależnych.
Przykłady:
* cielę
* jagnię
* źrebię
* szczenię
________________


-ter-
Funkcja: nomen agentis / nazwa funkcji / nazwa relacji.
Znaczenie: „ten, który wykonuje X / pełni funkcję X / pozostaje w relacji X”.
Typ: deradykalny.
Geneza:
 Kontynuuje PIE *-tēr / *-tōr, archaiczny formant nazw wykonawców, funkcji i relacji rodzinnych.
Przykłady:
* *ph₂tḗr „ojciec” (pacierz)
* *méh₂tēr „matka” (macierz)
* *bʰréh₂tēr „brat”
* *dʰugh₂tḗr „córka”
* *ǵenh₁tōr „rodziciel”
________________


B. Abstrakcja / stan / rezultat
-a-
Funkcja: nomen actionis / nomen rei / nomen abstractum.
Znaczenie: „stan X / proces X / rzecz lub rezultat związany z X”.
Typ: deradykalny, denominalny.
Geneza:
 Kontynuuje starą klasę ā-tematową, w znacznej części wywodzącą się z PIE *-eh₂.
Przykłady:
* rada
* bieda
* doba
________________


-o-
Funkcja: nomen rei / nomen actionis / nomen resultativum.
Znaczenie: „byt związany z X / wynik X / czynność ujęta jako rzecz”.
Typ: deradykalny.
Geneza:
 Kontynuuje indoeuropejskie formacje tematyczne na *-o-. W prasłowiańskim odpowiadają im m.in. rzeczowniki męskie na *-ъ i nijakie na *-o.
Przykłady:
* tok
* potok
* gród
* wóz
________________


-i-
Funkcja: nomen abstractum / nomen actionis.
Znaczenie: „stan X / właściwość X / abstrakcyjna treść X”.
Typ: deradykalny, dewerbalny.
Geneza:
 Kontynuuje PIE *-i-. W prasłowiańskim stare i-tematy dawały m.in. rzeczowniki na *-ь.
Przykłady:
* broń
* dań
* część
* cześć
________________


-m-
Funkcja: nomen rei / nomen actionis / nomen resultativum.
Znaczenie: „byt / stan / zjawisko / rezultat związany z X”.
Typ: deradykalny, dewerbalny.
Geneza:
 Kontynuuje starą rodzinę formacji na *-mo-. Prasłowiański zachował typy *-mъ, *-mo i *-ma.
Przykłady:
* *dymъ → dym
* *glumъ
* *kosmъ
* *šumъ → szum
________________


-mien- / -mię-
Funkcja: nomen actionis / nomen rei / nomen resultativum.
Znaczenie: „rezultat X / treść X / rzecz powstała przez proces X”.
Typ: głównie dewerbalny.
Geneza:
 Kontynuuje PIE *-men-, jeden z podstawowych formantów nazw czynności, rezultatów i produktów czynności. W prasłowiańskim zachował się w klasie na *-mę z tematem *-men-.
Przykłady:
* siemię
* brzemię
* znamię
* plemię
________________


-ć-
Funkcja: nomen actionis / nomen abstractum / nomen resultativum.
Znaczenie: „czynność X / stan X / rezultat procesu X”.
Typ: deradykalny, dewerbalny.
Geneza:
 Kontynuuje PIE *-ti-, jeden z podstawowych indoeuropejskich formantów nazw czynności.
Przykłady:
* śmierć
* pamięć
* część
* cześć
________________


-eż-
Funkcja: nomen actionis / nomen abstractum.
Znaczenie: „czynność X / przebieg lub rezultat czynności X”.
Typ: głównie dewerbalny.
Geneza:
 Prasłowiański formant *-ežь, rekonstruowany z wcześniejszego *-ezja-. Jego dalsza geneza pozostaje niejasna.
Przykłady:
* grabież
* *padežь „upadek”
* *mętežь „zamęt”
* *čьrtežь „rysunek”
________________


-eń-
Funkcja: archaiczna nominalizacja n-tematowa.
Znaczenie: „byt / przedmiot / nosiciel związany z X”.
Typ: deradykalny.
Przykłady:
* korzeń
* grzebień
* szerszeń
________________


C. Nazwy czynności / abstrakty
-(e)je-
Funkcja: nomen actionis / nomen abstractum / collectivum.
Znaczenie: „czynność X / stan X / zbiorowość X”.
Typ: dewerbalny, denominalny, deadiektywny.
Geneza:
 Prasłowiański formant *-ьje. Jego praindoeuropejskim źródłem jest kolektywny formant *-ey- / *-i-.
Przykłady:
* *kamenьje
* *ustьje → ujście
* dawne rzeczowniki zbiorowe i abstrakcyjne na *-ьje
________________


-ba-
Funkcja: nomen actionis / nomen rei / nomen abstractum.
Znaczenie: „czynność X / stan X / rezultat X”.
Typ: głównie dewerbalny.
Geneza:
 Stary bałtosłowiański i prasłowiański formant nazw czynności, w prasłowiańskim reprezentowany przez *-ba / *-ьba.
Przykłady:
* prośba
* służba
* drużba
* rzeźba
________________


D. Narzędzie / środek czynności
-tro-
Funkcja: nomen instrumenti / nomen rei.
Znaczenie: „to, czym wykonuje się X / przedmiot służący do X”.
Typ: dewerbalny.
Geneza:
 Prasłowiańskie *-dlo kontynuuje indoeuropejską rodzinę instrumentalną reprezentowaną przez typy *-dhlo-, *-tlo-, *-dhro- i *-tro-.
Przykłady:
* mydło
* szydło
* radło
* żądło
* jadło
________________


E. Formant ekspresywny
-uch-
Funkcja: nomen agentis / nosiciel cechy / augmentativum / pejorativum.
Znaczenie: „ten, którego wyraźnie charakteryzuje X”.
Typ: denominalny, deadiektywny, dewerbalny.
Geneza:
 Kontynuuje prasłowiański formant ekspresywny *-uxъ.
Przykłady:
* staruch
* pastuch
________________
