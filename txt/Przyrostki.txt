🔷 PRZYROSTKI 
I. PRZYROSTKI TWORZĄCE PRZYMIOTNIKI
-y / -i
Funkcja: adiektywizacja rdzenia (cecha wynikająca z bazy leksykalnej)
Znaczenie: “taki, który posiada cechę X / jest związany z X"
Typ: denominalny, deverbatywy
Produktywność: bardzo wysoka — rdzeń każdego przymiotnika prymarnego
Przykłady:
* biały → “mający cechę bieli" (psł. *bělъ)
* zły → “mający cechę zła / będący złym" (psł. *zьlъ)
* nowy → “mający cechę nowości" (psł. *novъ)
* młody → “mający cechę młodości" (psł. *moldъ)
________________


-k- / -ok- / -ek- / -ak-
Funkcja: tworzenie cechy wyodrębnionej z rdzenia, często z odcieniem intensywności lub kierunkowości
Znaczenie: “posiadający cechę X w sposób określony / uchwytny"
Typ: denominalny
Przykłady:
* miękki → “mający miękkość" (psł. *mękъkъ)
* gładki → “mający gładkość" (psł. *gladъkъ)
* rzadki → “mający rzadkość" (psł. *rědъkъ)
* słodki → “mający słodkość" (psł. *sladъkъ)
* głęboki → “sięgający w głąb" (psł. *golbokъ)
* szeroki → “rozciągający się wszerz" (psł. *širokъ)
* wysoki → “sięgający ku górze" (psł. *vysokъ)
________________


-n- 
Funkcja: materiałowość / źródłowość / związanie 
Znaczenie: “wykonany z X / dotyczący X"
Typ: denominalny i deverbatywy
Przykłady rzeczownikowe (denominalny):
* ziemny → “z ziemi / ziemisty" (ziemia + -n-)
* smutny → “napełniony smutkiem"
* wiosenny → “dotyczący wiosny"
* letni → “dotyczący lata"
* nocny → “dotyczący nocy"
Przykłady czasownikowe (deverbatywy):
* wolny → “ten, kto może woleć / nie jest przywiązany" (< vol- + -n-)
* ważny → “mający wagę / ciężar decyzyjny"
________________


-t- / -ty
Funkcja: tworzenie cechy posiadania lub podobieństwa wyodrębnionej z bazy leksykalnej
Znaczenie: “mający cechę X” → “mający cechę przybliżoną / trochę podobny do X”
Typ: denominalny
Geneza: element -ty- posłużył jako baza strukturalna do ukształtowania przyrostka -aty (psł. *-atъ), z którego następnie przez fuzję z przyrostkiem relacyjnym (psł. *-ov-) powstał formant złożony -owat-
Przykłady:
* kudłaty → „mający kudły”
* rogaty → „mający rogi”
* brodaty → „mający brodę”
* brodawkowaty → „trochę podobny do brodawki”
* głupkowaty → „mający pewne cechy głupka”
* workowaty → „kształtem przypominający worek”
________________


-ist- / -yst- / -ast- 
Funkcja: intensyfikacja cechy / obfitość / podobieństwo do X
Znaczenie: “obfitujący w X / pełen X / mający wiele X / podobny do X"
Typ: denominalny
Geneza: psł. *-istъ / *-astъ; paralele w łacinie *-ōsus (np. gloriosus, copiosus — nie *-ostus, które nie istnieje) i germańskim *-iska- (niem. -isch, ang. -ish); spokrewniony też z gr. -ίσκος
Przykłady:
* piaszczysty → “pełen piasku"
* krzaczasty → “pełen krzaków"
* mglisty → “pełen mgły"
* skalisty → “pełen skał / jak skała"
* ziarnisty → “mający ziarna / pełen ziaren"
* liściasty → “mający dużo liści"
________________


-sk-
Funkcja: przynależność do grupy, miejsca, narodu, osoby, zawodu
Znaczenie: “należący do X / będący z X / właściwy dla X"
Typ: denominalny
Geneza: psł. *-ьskъ, jedno z najproduktywniejszych
Przykłady:
* polski → “z Polski / dotyczący Polaków"
* krakowski → “z Krakowa"
* rycerski → “należący do rycerza / jak rycerz"
* wiejski → “dotyczący wsi"
* morski → “dotyczący morza"
* ludzki → “dotyczący ludzi"
* Bożyński, Kowalski → (nazwiska) “należący do Boga / kowala"
________________


-liw-
Funkcja: skłonność / skłonność do czynności, gotowość do przejawu cechy
Znaczenie: “mający skłonność do X / skłonny do X"
Typ: deverbatywy (od czasownika)
Geneza: psł. *-livъ
Przykłady:
* drażliwy → “łatwy do zdrażnienia"
* łagodliwy → “mający skłonność do łagodności"
* pojętliwy → “łatwo pojmujący"
* zapalczywy → “skłonny do zapalania się / gniewu"
* troskliwy → “pełen troski"
________________


-aw- (psł. *-avъ ← PIE -owos) 
Funkcja: przymiotnik naturalnej skłonności / zabarwienia / przynależności 
Znaczenie: "mający naturalną właściwość X / zabarwiony X / skłonny do X z natury" 
Typ: denominalny
Geneza: psł. -avъ ← PIE -owos — ablautowy wariant tego samego morfemu co -ovъ (-owy); podczas gdy -owy wyraża relację do X (dębowy, złoty), -awy wyraża naturalne zabarwienie lub skłonność — coś wrodzonego, nie przypisanego Uwaga: nie mylić z -owat- — -owat- = "trochę podobny do X" (brodawkowaty), -awy = "mający naturalną właściwość X" (krwawy, łaskawy); granica płynna, ale -awy silniejsze i bardziej konstytutywne 
Przykłady:
* krwawy → "mający krew / naznaczony krwią" (krew + -awy)
* łaskawy → "mający łaskę / z natury łaskawy" (łaska + -awy)
* ciekawy → "mający ciekawość / płynący ciekiem zainteresowania" (ciek- + -awy)
* głodnawy (dial.) → "trochę głodny" — tu granica z -owat-
* brudnawy → "mający brud / trochę brudny"
________________


-ł (psł. -lъ)
Funkcja: nomen resultativum — ten/to który wykonał czynność i nosi jej rezultat w sobie
Znaczenie: “ten, który X-ał i jest tym naznaczony"
Typ: deverbatywy
Geneza: psł. -lъ ← PIE -lo- — ten sam element który dał słowiański czas przeszły.
Przykłady:
* zgniły → “ten który zgnił i jest tym stanem"
* uschły → “ten który usechł"
* dojrzały → “ten który dojrzał i jest tym naznaczony"
* dorosły → “ten który dorósł — i jest tym na stałe"
* ogłupiały → “ten który ogłupiał"
* oniemiały → “ten który oniemiał"

________________


-ny / -ony (psł. *-nъ / -enъ / -tъ)
Funkcja: participium passivi — imiesłów bierny / przymiotnik rezultatywny
Znaczenie: "ten, któremu wykonano czynność X / będący w stanie po wykonaniu X / naznaczony przez X"
Typ: deverbatywy (od tematu czasownika)
Geneza: PIE *-no- (→ psł. *-nъ) 
Przykłady:
   * robiony → "ten, którego ktoś robi"
   * mazany → "ten, którego ktoś maże"
   * szyty → "ten, którego ktoś szyje"
   * cięty → "ten, którego ktoś tnie"
   * dany → "ten, którego ktoś daje"
   * rodzony → "ten, którego ktoś rodzi"
________________


II. PRZYROSTKI TWORZĄCE RZECZOWNIKI
A. Kategoria sprawcy / wykonawcy / nosiciela cechy
-nik / -nik- / -nica / -nica-
Funkcja: nomen agentis — wykonawca, nosiciel, ten związany z czymś
Znaczenie: “ten, kto X / ten, który zajmuje się X / ten, który posiada X"
Typ: denominalny
Geneza: psł. *-nikъ
Przykłady:
   * ogrodnik → “ten, kto zajmuje się ogrodem"
   * strażnik → “ten, kto strzeże"
   * dwornik → “ten, kto obsługuje dwór"
   * robotnik → “ten, kto wykonuje robotę"
   * lotnik → “ten, kto obsługuje lot" (lotnik)
   * prawnik → “ten, kto zajmuje się prawem"
________________


-acz
Funkcja: nomen agentis — wykonawca czynności (od czasownika)
Znaczenie: “ten, kto wykonuje czynność X"
Typ: deverbatywy
Geneza: psł. *-ačь
Przykłady:
   * palacz → “ten, kto pali"

   * kopacz → “ten, kto kopie"
   * zakreślacz → “ten, kto zakreśla"
________________


-arz / -erz
Funkcja: nomen agentis — wykonawca zawodu / rzemieślnik
Znaczenie: “ten, kto zawodowo zajmuje się X / wyrabia X"
Typ: denominalny i deverbatywy
Geneza: psł. *-arjь, pożyczka z łaciny -ārius przez germański -āri
Przykłady:
   * lekarz → “ten, kto zajmuje się leczeniem"
   * kucharz → “ten, kto gotuje"
   * malarz → “ten, kto maluje"
   * stolarz → “ten, kto robi stoły / meble"
   * murarz → “ten, kto muruje"
   * garncarz → “ten, kto robi garnki"
-ca 
Funkcja: nomen agentis — sprawca / ten, kto wykonuje czynność
Znaczenie: “ten, kto dokonuje X"
Typ: deverbatywy (od form bezokolicznikowych)
Geneza: psł. *-ьca
Przykłady:
   * śpiewca → “ten, kto śpiewa"
   * twórca → “ten, kto tworzy"
   * odbiorca → “ten, kto odbiera"
   * dawca → “ten, kto daje"
   * dawca → “ten, kto daje"
   * zbawca → “ten, kto zbawia"

-tel / -ciel
Funkcja: nomen agentis — wykonawca czynności, często o wyższej godności lub trwałości
Znaczenie: “ten, kto X (zawodowo / trwale / z godnością)"
Typ: deverbatywy
Geneza: psł. *-telь — pie. *-tēl
Przykłady:
   * nauczyciel → “ten, kto naucza"
   * modliciel → “ten, kto modli się / wstawia"
   * wybawiciel → “ten, kto wybawia"
   * pocieszyciel → “ten, kto pociesza"

-cierz/-torz/-cier (← PIE -tḗr/-tōr) [~]
Funkcja: archaiczny formant nominalny o pierwotnie agentywno-funkcyjnym charakterze (tworzący rzeczowniki oznaczające wykonawcę czynności, uczestnika lub nosiciela relacji/funkcji związanej z rdzeniem)


Znaczenie: “ten, który wykonuje czynność X / pełni funkcję X / jest związany rolą X wyrażoną przez rdzeń”


Typ: odziedziczony morfem PIE; w prasłowiańszczyźnie nieproduktywny ale utrzymujący się, zachowany w leksykalizacjach (zwłaszcza terminach pokrewieństwa i archaizmach), zastępowany później przez produktywne formanty słowiańskie (-nikъ, -telь, -ačь itd.). wyłącznie odrdzeniowy (bo jaki inny?)


Geneza: PIE -tḗr (w systemie atematycznych formacji rzeczownikowych; pierwotnie silnie związany z tworzeniem nazw ról i pokrewieństwa, częściowo agentywny, częściowo relacyjny; brak pełnej produktywności już w późnej warstwie PIE)


Przykłady (rekonstruowane):
   * pacierz → “ten, kto chroni" (*pH₂tḗr), agent od *peh₂- “chronić"  ~ agent od *pa-pa “papa”, zduplikowanego *pa. (żeby się nie zmylić - npol. “pacierz" pochodzi od łac. “pater”, nie bezpośrednio od PIE.)
   * macierz → “matka" (*méh₂tēr), agent od *méh₂-meh₂, “mama”, zduplikowanego *méh₂.
   * bracierz → “brat" ( *bʰréh₂tēr), agent należący do tej samej “fratrji”, organizacji pierwotnej (?)
   * dukcierz → “córka" (*dʰugh₂tḗr) — wewnętrzna etymologia niejasna i sporna. Dawna hipoteza o związku z rdzeniem *dʰewgʰ- “doić, produkować mleko" jest współcześnie odrzucana: oba rdzenie różnią się fonologicznie (*dʰewgʰ- ma dwie dźwięczne aspirowane, *dʰugh₂- tylko jedną, wtórną przez wpływ laryngalnego h₂), co wyklucza bezpośredni związek (Language Log, Hackstein 2002). Słowo jest jednym z najlepiej poświadczonych terminów pokrewieństwa PIE — kognaty w anatolijskim, greckim, indo-irańskim, bałtosłowiańskim — ale jego wewnętrzna motywacja pozostaje niepewna.
   * ahcierz  -> “ten, kto jest gorący, suchy" (*h₂eh₁ter), agent od *h₂eh₁- “być gorącym, suchym”
   * gencierz -> “ten kto produkuje, rodzi, (sprawia, że ktoś się staje jakiś)" (*ǵénh₁tōr), agent od  *ǵenh₁- “produkować, rodzić”

-dło / -tła / -sło / -sła / -śle / -tro / -tlo   (← PIE *-tro- / *-tlo-)


Funkcja: archaiczny formant nominalny o charakterze instrumentalnym (tworzący rzeczowniki oznaczające narzędzie czynności).


Znaczenie: “to, czym się wykonuje czynność X / to, co służy do X / mechanizm związany z rdzeniem X" (w przeciwieństwie do -tḗr, który wskazuje na osobę, ten formant wskazuje na przedmiot/narzędzie).


Typ: odziedziczony morfem PIE; w języku polskim i słowiańskim bardzo produktywny w formie -dło (powstałej przez udźwięcznienie t przed l), rzadziej zachowany jako archaiczne -tro.


Geneza: PIE *-tro- / *-tlo-; systemowy odpowiednik formantu agentywnego -tḗr. Służył do uprzedmiotowienia czynności. W łacinie dał -trum (aratrum), w grece -tron (theatron).


Przykłady (narzędzia/środki):
   * wiatr → (*u̯ē-tro-) “to, co wieje" / “narzędzie wiania" (natura jako mechanizm).
   * żądło → (*źęd-dlo) “to, czym się żga / kłuje”.
   * szydło → (*šy-dlo) “to, czym się szyje”.
   * sidło → (*sě-dlo) “to, co służy do siadania (chwytania)" lub od osaczania.
   * mydło → (*my-dlo) “to, co służy do mycia”.
   * radło → (*ordlo) “to, czym się orze”.
   * ciosła → (*tes-sla) “to, czym się cieśli"


Przykłady (miejsca/wyniki)
   * piętro → (*pęt-tro) pierwotnie “stopień" lub “to, po czym się pnie (wspina)”.
   * gardło → (*gьr-dlo) “to, czym się pożera / graba”.
   * siodło → (*sed-lo) “to, na czym się siedzi”.
   * źródło → (*žer-dlo) “to, co wrze / wytryska”.

-uń / -un (psł. *-unь)
Funkcja: nomen agentis / hypocoristica — nosiciel cechy, często z odcieniem pieszczotliwym, żartobliwym (~ -uń) albo pejoratywnym (~ -un).
Znaczenie: “ten, który ma cechę X / ten, który wykonuje X (z odcieniem afektywnym)"
Typ: denominalny i deadiektywny
Geneza: psł. *-unь — prawdopodobnie z PIE *-un- (element sufiksalny obecny w wielu IE); w słowiańskim rozwinął się w kierunku hipokorystycznym
Przykłady:
   * śpiun → “ten, co śpi"
   * gaduń → “ten, co gada"
   * złodun (dial.) → “ten, co źle postępuje"
   * ćpun → “ten, co ćpa"
   * biegun → “ten, co biega / biegun jako punkt ruchu"
   * pływun → “ten, co pływa"

-taj/-otaj/-ataj (psł. *-tajь ← bsł. *-tājas ← PIE *-teh₂-i̯o-s) {https://journals.akademicka.pl/lv/article/download/420/3966/5964}
Funkcja: nomen agentis — wykonawca czynności jako stały, powtarzający się jej podmiot
Znaczenie: “ten, który X-uje często / stale / nałogowo" — nosiciel roli
Typ: odrdzeniowy (deverbatywy)
Geneza: PIE *-teh₂- → pierwotnie sufiks iteratywno-frekwentatywny czasowników ("robić coś często / stale"); przeniesiony do nomina agentis, gdzie zachował odcień habitualności; wzmocniony o *-i̯o- w bałtosłowiańskim (bsł. *-tājas); w słowiańskim uproszczony do *-tajь.    * lit. ieškótojas → “poszukiwacz" (: ieškóti “szukać")

Funkcja: nomen abstractum — abstrakt stanu / jakości / koloru / właściwości jako byt wewnętrzny

Geneza: psł. *-anije, *-enije — jeden z najproduktywniejszych typów
Przykłady:

   * pisanie → “czynność pisania"
   * śpiewanie → “czynność śpiewania"
   * myślenie → “czynność myślenia"
   * marzenie → “czynność marzenia"

-ga (psł. *-ga, f.)
Funkcja: dewerbalny formant nominalny — wynik / produkt procesu wyrażonego rdzeniem

Typ: odrdzeniowy (deverbatywy)
Geneza: PIE *-gʰo-, *-gʰeh₂ — pokrewne z lit. *-gas, pgerm. *-gô; synonimy w psł.: *-ba, *-da, *-tva, *-ežь

-er/-or/-ra/-ry (*-ъrъ / *-rъ / -ra < PIE *-r̥ / *-reh₂)
Funkcja: element sonantyczny tworzący rzeczowniki dynamiczne (bez *-o-) lub stanowiący bazę przymiotników cechowych w połączeniu z sufiksem *-y/-i (→ -ry = -r- + -y) 
Geneza: PIE *-r̥ (sonant sylabiczny); wariant tematyczny *-r̥ + *-o- + *-y → psł. przymiotniki na -ry; wariant atematyczny *-r̥ bez tematycznego → psł. *-ъrъ (rzeczowniki)
Uwaga morfologiczna: *-ro- (przymiotnikowe) i *-ъrъ (rzeczownikowe) są ablautowymi wariantami PIE *-r̥, tak jak *-to- i *-t̥ są wariantami tego samego *t. Sufiks *-tro- (instrumentalny, jak w *-dło) jest dalszym rozszerzeniem przez *-t- i jest morfologicznie odrębny, choć spokrewniony przez wspólne *-r̥.
Typ: odrdzeniowy (radikalny) — rdzeń werbalny lub nominalny bez pośredników
Przykłady przymiotnikowe (*-ro- > psł. *-rъ):
   * dobry ← psł. *dobrъ ← PIE *dʰh₂obʰ-ro-s od *dʰh₂ebʰ- “kształtować, dopasowywać, pasować" → “właściwie ukształtowany / stosowny" por.  doba “coś odpowiedniego”
   * ostry ← psł. *ostrъ ← PIE *h₂eḱ-ro- od *h₂eḱ- “ostry, spiczasty" (por. łac. ācer, gr. ákros)
   * stary ← psł. *starъ ← PIE *steh₂-ro- od *steh₂- “stać, trwać" → “ten który stoi od dawna / utrwalony"
   * mądry ← psł. *mǫdrъ — rdzeń *men- “myśleć" z rozszerzeniem *-dʰ- + *-ro-
Przykłady rzeczownikowe (*-r̥ / *-reh₂ > psł. *-ъrъ / *-ra, realizacja dynamiczno-intensywna):
   * wicher ← psł. *vixъrъ od *vixati “wirować, kręcić" + *-ъrъ → “to, co wiruje, kręci się" (WSJP PAN: explicite *vixъrъ od *vixati + przyrostek *-ъrъ)
   * woda ← psł. *voda ← bsł. *wandō ← PIE *wédōr (kolektyw r/n-stem ← *wódr̥) ← rdzeń *wed- / *ud- "płynąć, tryskać"
   * igra ← psł. *jьgra ← wcz. psł. *ígrā ← bałt.-sł. *ígrāˀ ← PIE *h₂ig-réh₂ ← *h₂eyg- „poruszać, wprawiać w ruch”

-icz (psł. *-it'ь)
Funkcja: patronimicum / zdrobnienie — syn / potomek / mała wersja X
Znaczenie: “syn X / potomek X / ten który pochodzi od X / mały X"
Typ: denominalny
Geneza: psł. *-it'ь ← PIE *-ikos (przez bałtosłowiański) — spokrewniony z *-ьcь / *-ec*, z którym dzieli wspólnego przodka; palatalizacja *tj > č* dała warianty w poszczególnych językach
Produktywność: żywy w rosyjskim i serbsko-chorwackim; w polskim zachowany jedynie jako relikt w nazwiskach
Przykłady:
● królewicz → “syn króla"
● carewicz → “syn cara"
● Janowicz, Adamicz → “syn Jana / Adama" (polskie relikty nazwiskowe)
● Petrovič (serb.) → “syn Petra"
● Ivanovič (ros.) → “syn Ivana"
